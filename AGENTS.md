# Работа со стендом

1. Прочитай [README](README.md) и проверь `git status`. Соблюдай контракт каталога, правила изоляции, соглашения об импортах, токенах, документации и QA.
2. Работай в `experiment/<slug>` от актуальной `main`. Сценарий и его демоданные храни в `app/src/experiments/<slug>/`. Для Vue-команд используй `app/`.
3. Перед публикацией запусти форматирование, `git diff --check` и полный `npm run qa`. При ошибке исправь причину и повтори полный прогон. Проверяй SHA деплоя, прямой маршрут и возврат к каталогу.
