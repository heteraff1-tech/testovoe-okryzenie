# Работа со стендом Bootstrap

1. Прочитай [README](README.md) и проверь `git status`. Для новых сценариев создай ветку `experiment/<slug>` от актуальной `main`.
2. При переносе из Figma открой макет, прочитай [инструкции дизайн-системы](https://github.com/heteraff1-tech/desingSystem/blob/main/AGENTS.md) и выбери профиль Bootstrap 5.3. До написания Vue-компонента разреши ключи опубликованных компонентов через `npm run --silent design:lookup -- <ключи>` из `app/`. Используй вариант из каталога и нативную разметку Bootstrap. Для `custom-required` зафиксируй отсутствующую обёртку, когда готовой реализации нет.
3. Используй сетку, утилиты и переменные Bootstrap. Сырые цвета и произвольные отступы, радиусы, тени и размеры текста запрещены. Для цветов используй `--bs-*`, для отступов используй классы Bootstrap или общую шкалу `--ds-space-*`. Новые правила применения токенов описывай вместе с изменением.
4. Храни сценарии в `app/src/experiments/<slug>/` и изолируй их друг от друга. Соблюдай импорты `pages → features → shared`. Подключай feature через публичный `index.js`. Используй семантическую разметку, видимый фокус и подписи полей.
5. Перед публикацией запусти `npm run format` и `npm run qa` из `app/`, затем `git diff --check`. Проверь основной путь с клавиатуры и на ширине 375 px. Исправляй причину падения проверки и повторяй полный QA.
