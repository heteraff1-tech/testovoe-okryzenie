# Стенд Bootstrap 5.3 на Vue

Стенд использует Vue 3, Bootstrap 5.3, Sass и Vite. Стартовая страница показывает канонические привязки из [каталога дизайн-системы](https://github.com/heteraff1-tech/desingSystem/blob/main/index.md) и находит их по ключу Figma, по имени или по классу.

## Запуск

Выполняй команды из `app/` на Node.js 22.12 или новее.

```sh
npm ci
npm run dev
```

Vite собирает сайт в `app/dist/`. Статическая публикация использует `app/` как рабочую папку.

## Перенос из Figma

1. Открой нужный экран и определи основной опубликованный компонент каждого экземпляра. Для варианта используй ключ родительского набора и значения свойств варианта.
2. Перед написанием разметки разреши ключи одним запросом. Точное имя канона подходит, если ключ недоступен.

   ```sh
   npm run --silent design:lookup -- 3aad87adb4de2ef06be25cffb9cc28a7864c7268 input modal
   ```

3. Сверь поля `variants`, `avoidWhen` и `source` из результата. Используй `implementation` для выбора нативной разметки и классов Bootstrap. Например, `button` даёт `.btn`, а для варианта primary к ней добавляется `.btn-primary`. Экземпляр поля `input` использует `<input class="form-control">`.
4. Для `custom-required` найди готовую Vue-обёртку в `src/shared/` или зафиксируй отсутствующую реализацию. Для `unmapped` проверь ключ родительского набора и источник. Проверка неизвестного ключа завершает команду с ненулевым кодом.
5. Для цвета используй утилиты Bootstrap или существующие `--bs-*`. Для отступов используй утилиты `m-*`, `p-*`, `gap-*` или `var(--ds-space-*)`. Значения последней шкалы генерируются из Bootstrap `$spacers`. Для скруглений, теней и типографики выбирай классы или переменные Bootstrap. Открой экран в обеих темах, проверь клавиатуру и ширину 375 px.

Снимок привязок и ревизия источника записаны в `app/design-system/bootstrap-catalog.json`. Чтобы подтянуть новую ревизию, обнови checkout репозитория `desingSystem`, затем выполни команду из `app/`.

```sh
npm run design:sync -- /путь/к/desingSystem
```

## Проверки

```sh
npx playwright install chromium
npm run qa
```

QA проверяет форматирование, границы импортов, привязки Figma, темы и шкалу Bootstrap, отсутствие сырых цветов и произвольных значений в стилях, production-сборку и браузерные сценарии. Тесты стилей разбирают CSS, SCSS, шаблоны Vue и статические значения в JS/TS. Playwright проверяет поиск, диалог с клавиатуры, переключение темы и мобильную ширину. GitHub Actions запускает тот же QA при push в `main` и `experiment/**`, а также в pull request.
